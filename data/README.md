# Data

Place the IBM Telco Customer Churn CSV in this folder.

Expected filename:

`WA_Fn-UseC_-Telco-Customer-Churn.csv`

The raw dataset is intentionally not included in this repository. This keeps the repository lightweight and avoids redistributing third-party data without confirming its current licensing/usage terms.

Expected target column:

`Churn`

Common columns include customer tenure, contract type, payment method, monthly charges, total charges and service subscriptions.
